# RadiestesiaPro

Página pública do app RadiestesiaPro: <https://luizflaviomatias.github.io/radiestesiapro/>

- O botão de download lê `https://luizflaviomatias.github.io/apps/radiestesiapro/versao.json`, publicado pelo repositório `apps`.
- Termos de Uso e Privacidade ficam em `apps/termos/radiestesiapro/` e `apps/privacidade/radiestesiapro/`.
- O código do app é privado. Nada de chaves ou segredos neste repositório.
- A seção **Tutorial** usa o vídeo em `tutoriais/` (MP4, WebM, poster, legendas e capítulos em WebVTT), com `tutorial.css` e `tutorial.js`.
